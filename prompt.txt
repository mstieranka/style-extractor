Goal:
Extract a color palette from the provided CSS.

Hard rules:
- Use ONLY information from the CSS input. Do not use outside knowledge.
- Do NOT invent colors.
- A color value must be a CSS color literal that appears in the input (e.g., #hex, rgb/rgba, hsl/hsla, oklch/oklab, color(), named colors).
- If a candidate value is var(--x), you may resolve it ONLY if --x is defined in the provided CSS. If resolvable, return the resolved literal color. If not resolvable, return null (do not output var(...)).
- Do not convert between color spaces. Preserve the exact literal token from the input.
- If a light theme and a dark theme are both present, choose the light theme values.
  Theme detection:
  - "Dark theme" scopes include: @media (prefers-color-scheme: dark), [data-theme="dark"], .dark, :root.dark
  - "Light theme" scopes include: @media (prefers-color-scheme: light), [data-theme="light"], .light, :root.light, and the default :root (not in a dark scope)

Selection rules (when multiple candidates exist for a key):
1) Prefer CSS custom properties (variables) whose name matches the key or one of its synonyms (exact token match > substring match).
2) If still ambiguous, prefer the candidate that is used in the most semantically relevant property/selector:

   - surface: background on any card element or an element that is located inside the app root and has a color different to the background, but in most cases still with low saturation
   - primary: background or text on a brand element, usually with high saturation, whichever is lighter
   - primaryVariant: background or text on a brand element, usually with high saturation, whichever is darker
   - text/muted: color on body/typography selectors
   - border/ring: border-color/outline/box-shadow
   - link: a, .link, :link, :visited
3) If still tied, choose the first defined in the selected theme scope.

Return ONLY valid JSON matching this schema. Include all keys exactly once. No extra keys. No markdown. DO NOT omit any keys in the color object. If the color value for a key cannot be found, return null for this key.
